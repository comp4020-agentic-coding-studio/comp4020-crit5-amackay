# Crit 5 — reflection


## What was the breakthrough that moved the work forward?

I started off with one idea for a game, but got stuck in the initial design phase - there were too many details to figure out. Eventually I stopped, and went with a simpler idea with less design decisions to figure out.


## What did this work change about who I want to be as a software developer?

I realised that there is still a lot of software interface design intuitions that I have that agents do not yet. My role going forward will probably increasing involve answering questions like "what feels good for the user?" and "what would the user want in this case?"
